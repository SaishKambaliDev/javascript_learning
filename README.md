## ▶️ Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/SaishKambaliDev/javascript_learning.git
   ```

2. Navigate to the project directory:

   ```bash
   cd javascript_learning
   ```

3. Open the project folder in VS Code.

4. Run the HTML file in your browser or use the Live Server extension where applicable.
